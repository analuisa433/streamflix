# streamflix
A plataforma de streaming StreamFlix quer reformular seu motor de recomendação e
controle de catálogo de mídia. O sistema deve cadastrar episódios, filmes e séries,
registrando visualizações e calculando as métricas de tempo total consumido e
recomendação por faixa etária.

Autores: Ana Luisa, Giovana e Natália
